Traffic Light Control

An Arduino Uno and Wokwi-based two-direction traffic-light simulation, including adjustable green durations, an I2C LCD countdown, and an all-red transition interval.

Project files and instructions: "Arduino/Traffic-Light-Control" (Arduino/Traffic-Light-Control/README.md).
